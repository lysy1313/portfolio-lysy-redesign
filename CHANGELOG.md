# Changelog

## 2.3.1

- Исправлен `package-lock.json`: удалена внутренняя ссылка на недоступный Artifactory для `@emailjs/browser`; пакет теперь загружается с публичного `https://registry.npmjs.org/`.
- Добавлен проектный `.npmrc`, чтобы последующие установки и обновления зависимостей использовали публичный npm registry.
- Код приложения и поведение EmailJS-формы не изменены.

## 2.3.0

- Исправлено обрезание бейджей `React` и `TypeScript` в hero: у визуального контейнера удалён paint containment, карточка получила безопасные боковые отступы, а бейджи больше не выходят за его границы.
- Карточка проекта «Магазин» переведена с CSS-мока на адаптивный WebP-скриншот, созданный по предоставленному изображению.
- Добавлен пятый проект «Старое портфолио» с архивным превью, точной live-ссылкой и явной пометкой предыдущей версии.
- Возвращена реальная отправка сообщений через EmailJS с теми же service/template/public key и именами полей, что использовались в предыдущем портфолио.
- Добавлены состояния `sending`, `success` и `error`, блокировка повторной отправки, spinner и доступный live-region.
- EmailJS-конфигурацию можно переопределить через `VITE_EMAILJS_*`, при этом проект работает без дополнительной настройки.
- Intrinsic-высота секции проектов увеличена с учётом пятой карточки; устаревшая CSS-разметка макета магазина удалена.
- Выполнены TypeScript-, ESLint-, production- и 22 браузерные проверки, включая два сценария EmailJS, desktop/mobile overflow и проверку `animation-timeline`.

## 2.2.0

- Главный экран на ширинах от `900px` теперь занимает ровно один viewport: заголовок, описание, кнопки, статистика и кодовая карточка полностью видны без обрезания.
- Размер заголовка учитывает одновременно ширину и высоту окна через `min(vw, svh)`, а для низких экранов добавлены отдельные компактные режимы.
- На мобильных устройствах hero сохраняет естественный вертикальный поток, чтобы не жертвовать размером текста и доступностью.
- Критический текст hero больше не скрывается через `opacity: 0`, поэтому LCP-элемент отображается сразу, а entrance-анимация остаётся на композитном `transform`.
- Индикатор прокрутки переведён на нативный `animation-timeline: scroll()`; JavaScript остаётся только fallback-сценарием.
- Убрана принудительная перекомпоновка из основного scroll-пути. Состояние шапки теперь отслеживается через `IntersectionObserver` и верхний sentinel.
- Tilt-эффект кеширует геометрию при `pointerenter` и обновляет CSS-переменные через `requestAnimationFrame`, не вызывая `getBoundingClientRect()` на каждом движении указателя.
- Для секций ниже первого экрана включены `content-visibility: auto` и безопасные intrinsic-размеры, уменьшающие стартовую работу layout/paint.
- Изображения проектов получили адаптивные варианты `480w`, `768w` и `1200w`, корректные `srcset`, `sizes`, lazy loading и async decoding.
- Удалены необязательные тяжёлые blur/backdrop-filter эффекты, а reveal карточек переведён с `clip-path` на opacity/translate/scale.
- В контрольном production-запуске Lighthouse: Performance `97 → 100`, LCP `1.7 → 1.5 с`, TBT `180 → 50 мс`, переданный объём `280 → 140 КБ`.
- Выполнены TypeScript-, ESLint-, production-, Lighthouse- и 32 браузерные проверки.

## 2.1.0

- Убран `filter: blur(...)` из всех контентных reveal-анимаций.
- Scroll-driven reveal теперь завершается раньше: элементы становятся полностью резкими уже в начале входа во viewport.
- Fallback через `IntersectionObserver` запускается немного заранее, чтобы контент не задерживался в промежуточном состоянии.
- Добавлена единая адаптивная шкала типографики в `src/styles/tokens.css`.
- Увеличены описания и теги навыков, подписи и значения в разделе «Обо мне», контактные данные, подписи формы и вспомогательный текст.
- Сохранены `animation-timeline: view()`, `prefers-reduced-motion`, sticky-проекты и мобильные fallback-сценарии.
- Выполнены TypeScript-, ESLint-, production- и браузерные проверки.
